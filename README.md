# JAVA APNA COLLEGE

This repository is a study and practice workspace for Java programming concepts from the Apna College course. It contains Java source files, compiled class files, and chapter-wise practice exercises organized by topic.

## Repository Overview

- `Chapter1,Variable&DataTypes/` — Java basics, variables, data types, arithmetic, input/output.
- `Chapter2,LiveClass/`, `Chapter2,Operator/` — Conditional logic, operators, and live-class exercises.
- `Chapter3,Conditional/` — `if`, `if-else`, `switch`, and decision-making examples.
- `Chapter4,Loops/` — `for`, `while`, `do-while`, and loop practice problems.
- `Chapter5,Pattern(1)/`, `Chapter7,Pattern2/` — Pattern printing and nested loop exercises.
- `Chapter6,Functions&Methods/` — Methods, return types, parameter passing, recursion basics.
- `Chapter8,Arrays(Pattern1)/`, `Chapter9,Arrays2(practise session10)/` — Array operations and search algorithms.
- `Chapter10,Sorting/` — Sorting algorithms such as bubble sort, selection sort, counting sort, and Java built-in sort.
- `Chapter11,2DArray/` — 2D array handling, matrix traversal, transpose, and sorted matrix search.
- `Chapter12,String/` — String manipulation, comparisons, and string-based problems.
- `Chapter13,BitManupulation/` — Bitwise operations and binary tricks.
- `Chapter14,OOPS/` — Object-oriented programming, classes, objects, inheritance, polymorphism.
- `Chapter15,Recursion/`, `Chapter16,Recursion2/` — Recursive algorithms and backtracking foundations.
- `Chapter17,DivideAndConquer/` — Divide-and-conquer strategies and algorithms.
- `Chapter18,TimeComplexity/` — Algorithm complexity and performance reasoning.
- `Chapter19,BackTracking/` — Backtracking problems such as subsets, permutations, and combinations.
- `Chapter20,ArrayList/` — Java `ArrayList` usage and list operations.
- `Chapter21,LinkedList/`, `Chapter22,LinkedList2/` — Linked list implementations and manipulations.
- `Chapter23, STACK(Part 1)/`, `Chapter24, Stack 2/` — Stack data structure and stack-based algorithms.
- `Chapter25,Queue/` — Queue behavior and implementation exercises.
- `Chapter26,GreedyAlgorithm/` — Greedy problem solving and optimization tasks.
- `Chapter27,BinaryTree(Part 1,2)/`, `Chapter29,BinaryTree(Part 3)/` — Binary tree traversal, construction, and operations.
- `Chapter30,BinarySearchTree/` — BST insertion, search, and tree-based problems.
- `Chapter31,Balanced BST/` — Balanced binary search tree concepts.
- `Chapter32,Heaps/` — Heap data structure and priority queue examples.
- `Chapter33,Hashing/` — Hash tables and map-related practice.
- `Chapter34,Tries/` — Trie structures and string prefix problems.
- `Chapter35,Graph,Part1/` through `Chapter40,GraphSupliments/` — Graph theory, traversal, shortest paths, and advanced graph topics.
- `Chapter41,DP(Part 1)/` through `Chapter46,DP,part6/` — Dynamic programming practice across multiple chapters.
- `Chapter47,SegmentTrees/` — Segment tree problems and range queries.
- `Chapter48,ExceptionHandling/` — Exception management and Java error handling.
- Other standalone files, examples, experiments, and practice problems are stored in the repository root.

## How to Use

1. Open the repository in VS Code or your preferred Java IDE.
2. Navigate to the chapter folder that matches the concept you want to study.
3. Compile a Java file with `javac`:

   ```bash
   javac Chapter10,Sorting/BubbleSorting.java
   ```

4. Run the compiled class with `java`:

   ```bash
   java Chapter10,Sorting/BubbleSorting
   ```

5. For files in the root directory, compile directly:

   ```bash
   javac main.java
   java main
   ```
